How a prediction is made

  1. 1
    URL validation

    Input is checked and normalised — no scheme, whitespace, or malformed text passes through.

  2. 2
    Feature extraction

    28 lexical features are computed directly from the URL string: length, structure, entropy, keywords, and more.

  3. 3
    Model prediction

    A trained Gradient Boosting classifier outputs a phishing probability.

  4. 4
    Risk + explanation

    The probability maps to a risk level, and SHAP explains exactly which features drove it.

    Why not just accuracy?

    In phishing detection the two mistakes are not equally costly. A false negative (missed phishing site) lets an attack through — this is what recall measures. A false positive (legitimate site flagged) erodes user trust — this is what precision measures. This project reports both alongside accuracy rather than accuracy alone.

    About this project

    Objective

    URLGuard predicts whether a URL is likely to be phishing or legitimate using only features computed from the URL text, and explains every prediction with real SHAP values — no hard-coded logic or canned explanations.

    Dataset

    PhiUSIIL Phishing URL Dataset (Prasad & Chandra, 2024, Computers & Security) — 235,795 labelled URLs from the UCI Machine Learning Repository. Only the raw URL and label were used; page-content-derived columns were discarded to avoid data leakage. See the README for full details.

    Risk levels

    Phishing probabilityRisk level
    Below 30%Low Risk
    30% – 70%Medium Risk
    70% and aboveHigh Risk

    Limitations

    • Lexical features only — no page content, WHOIS, or certificate checks, so a phishing page hosted on a clean-looking URL may be missed.
    • Subdomain counting uses a simple heuristic, not a full public-suffix list, so multi-part TLDs (e.g. co.uk) are slightly over-counted.
    • Trained on one dataset; real-world phishing patterns evolve and periodic retraining would be needed in production.

    Tech stack

    Python · Pandas · NumPy · Scikit-learn · SHAP · Joblib · Flask · vanilla HTML/CSS/JS
